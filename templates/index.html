Important dates this term (holidays, deadlines, exams)
    How to add this to Google Calendar, Outlook or Apple Calendar
    • Each class is saved as one repeating weekly event, so editing or deleting it asks "this event or all events?", and you can change the whole series at once.
    • Tip: create a new calendar first (for example "AUPP Spring 2027") and import into it. To undo everything later, delete that one calendar.
    • Google Calendar: open calendar.google.com on a computer, then Settings (gear) → Import & export → Import, choose the .ics file and pick the calendar. (The phone app can't import files; import on the web and it syncs.)
    • Outlook: Outlook on the web → Add calendar → Upload from file. Desktop Outlook: File → Open & Export → Import/Export → Import an iCalendar (.ics) file.
    • Apple Calendar: double-click the .ics file and choose the calendar (a new one is best).
    • Importing the same file again updates the same events instead of duplicating them.
    • Holidays, the add/drop and withdrawal deadlines, and the exam period come from the academic calendar as all-day events (free time). Deadlines also remind you the day before and three days before.
